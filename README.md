## 🚀 Getting Started

```bash
# clone the masterpiece
git clone https://github.com/FahmiMj/godot-gta7.git
cd godot-gta7

# open in Godot 4.7+
godot --editor .

# press F5
# witness the cube
# cry a little
```

If it doesn't work, close it and open it again. That's the whole debugging strategy.
